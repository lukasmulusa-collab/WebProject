## Overview

This project is an interactive, responsive personal portfolio website developed as part of the ICT251 Web Technologies Activity 3 coursework. Building upon Activity 2, this website highlights my background as a Computer Science student, showcases my learning path, displays multimedia content, and provides dynamic client-side interactivity using modern HTML5, CSS3, and JavaScript (ES6+).

The website is hosted publicly as a static site using Render and is connected directly to a GitHub repository for continuous deployment.
